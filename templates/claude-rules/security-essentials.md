# セキュリティ必須ルール

全セッションで常時適用する最低限のセキュリティルール。
詳細な規約・レビューチェックリストは別途参照。

## 絶対禁止（全プロジェクト共通）

1. **シークレットのハードコード禁止**: API key, パスワード, トークン, 接続文字列, 秘密鍵をコードに書かない
2. **新規コードでのSQL文字列結合禁止**: `$"SELECT ... {variable}"` は禁止。パラメータ化必須
3. **ログへの機密情報出力禁止**: パスワード、トークン等をログに含めない

## 2層基準（概要）

- **新規プロジェクト**: 全セキュリティルール厳守。違反は即ブロック
- **レガシー**: 新規コードは厳守。既存コードは修正容易な場合のみ

## コードレビュー時

セキュリティ観点の詳細なチェックリストは `rules/forbidden-files.md` を参照すること。
